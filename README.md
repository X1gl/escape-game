# ESCAPE PROTOTYPE

スマートフォン向け推理・脱出ゲームの本制作に先立ち、ノベル、4方向の探索、アイテム、謎解き、オートセーブを一通り検証するための静的Web試作版です。本番の物語・画像・音声は使用せず、CSSによる仮素材で構成しています。

## 遊び方

1. `はじめから` でオープニングを開始し、画面タップで会話を進めます。
2. 脱出パートでは左右の矢印で視点を変え、部屋の気になる場所をタップします。
3. 取得したアイテムは画面下部で選択・選択解除できます。数字のメモの `＋` から拡大確認できます。
4. 手がかりを使ってテンキーを解除し、出口をタップするとエンディングへ進みます。
5. 進行は自動保存され、次回は `つづきから` で復帰できます。

ローカル確認では `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。JSONをfetchするため、`index.html` の直接表示では動作しません。相対パスのみを使用しているためGitHub Pagesにもそのまま配置できます。

## ファイル構成

```text
index.html             画面とモーダルの基本構造
style.css              iPhone縦画面優先の表示・仮背景
js/game.js             画面遷移、探索、アイテム、セーブのゲームロジック
js/audio.js            将来の効果音追加用インターフェース
data/scenario.json     オープニング／エンディングのノベルデータ
data/room.json         方向、割合指定Hotspot、アイテム、謎解きデータ
assets/images/         将来の背景・立ち絵・表情・アイテム・イベントCG
assets/audio/          将来のUI・入手・感情表現効果音
```

部屋を増やす際は `data/room.json` の構造を `data/rooms/room01.json` などへ、章を増やす際は `data/scenario.json` を章単位へ分割できます。Hotspotは背景に対する `%` の矩形で定義しています。

## セーブ方式

ブラウザの `localStorage` に `escape-prototype-save-v1` というキーで、モード、ノベル位置、方向、所持・選択・取得済みアイテム、箱・テンキー・脱出などのフラグをJSON保存します。重要な操作のたびにオートセーブされます。`はじめから` は既存データを削除して初期状態を保存します。
